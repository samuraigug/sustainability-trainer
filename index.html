Как открыть файл на iPhone

Просмотрщик документа может показывать HTML без выполнения кода. Открой веб-версию тренажёра в Safari — она работает по обычной ссылке.

Открыть тренажёр в браузере

На компьютере автономный HTML можно открыть в обычном браузере. Вопросы, уроки и кейсы находятся внутри файла. Прогресс хранится отдельно на каждом устройстве и адресе; перенести его можно через резервную копию в разделе «Источники и сохранения».
